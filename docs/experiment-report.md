# Mini-VLA 实验报告

## 实验设置

数据集为 `lerobot/libero_10`：10 个任务、379 条 Episode（轨迹）、101,469 帧，包含主相机和腕部相机两路 RGB、8 维 State（机器人状态）、7 维 Action（动作）。项目采用冻结的 ImageNet 预训练 MobileNetV3-Small；全局视觉缓存每个视角为 576 维。语言由冻结的 MiniLM 编码为 384 维向量。

Mini-VLA 阶段按 Episode-level Stratified Split（按任务分层的轨迹级划分）拆为 303/38/38 条训练、验证、测试轨迹，对应 81,126/10,118/10,225 帧。以下视觉对照均在这一阶段的数据划分和评测口径中比较。

## 简单融合基线

保持 State、Language、动作标签与训练条件一致，只改变视觉输入。

| 模型 | 测试 MAE | 相对 State+Language |
|---|---:|---:|
| State + Language | **0.088374** | 基线 |
| Main + State + Language | 0.096104 | +8.75% |
| Wrist + State + Language | 0.094052 | +6.42% |
| Dual + State + Language | 0.093733 | +6.06% |

简单拼接下加入视觉没有超过基线，因此不能用这一阶段的结果声称视觉已提升泛化性能。

## 测试时视觉干预

固定同一个 Dual Mini-VLA、State、Language、测试集和动作标签，只改视觉特征。

| 条件 | MAE | 相对正确视觉 | 动作预测变化幅度 |
|---|---:|---:|---:|
| 正确视觉 | **0.093733** | 0% | 0 |
| 主相机置零 | 0.170221 | +81.60% | 0.142918 |
| 腕部相机置零 | 0.171370 | +82.83% | 0.143295 |
| 双相机置零 | 0.253782 | +170.75% | 0.236544 |
| 全局错配视觉 | 0.278478 | +197.10% | 0.268715 |
| 同任务内错配视觉 | 0.266721 | +184.55% | 0.254821 |

删除、全局错配和同任务换帧都会明显抬高误差，支持模型使用两路、且与当前帧相关的视觉信息；单相机的独立贡献不能按这些变化线性拆分。

## 时间错位干预

LIBERO 帧率为 10 FPS。固定模型，仅沿同一条轨迹时间轴错位视觉。

| 视觉错位 | MAE | 相对正确视觉 | 动作预测变化幅度 |
|---:|---:|---:|---:|
| 0 秒 | **0.093733** | 0% | 0 |
| 0.1 秒 | 0.094475 | +0.79% | 0.036200 |
| 0.5 秒 | 0.112833 | +20.38% | 0.077297 |
| 2 秒 | 0.222641 | +137.53% | 0.198413 |
| 5 秒 | 0.322359 | +243.91% | 0.303866 |

误差与预测变化随错位增加而扩大，支持模型利用时间敏感的视觉状态；这不识别物体位置等单一因素的独立因果贡献。

![视觉时间错位与测试 MAE 的关系](figures/temporal-shift.svg)

## 融合与空间表示迭代

投影融合将主/腕视觉、State、Language 分别投影为 256/256/64/128 维后融合。它将双视觉 MAE 从 0.093733 降至 0.087860（改善 6.27%），但仍比投影架构的 State+Language 高 0.32%。

项目进一步保留 MobileNet 特征图的 3×3 Spatial Grid（空间网格），再进行空间投影；它避免将视觉信息直接全局平均为单一 576 维向量。

| 模型 | 测试 MAE | 结果 |
|---|---:|---|
| 投影 State + Language | 0.087578 | 同架构基线 |
| 投影 Global-Pooled Dual | 0.087860 | 比基线高 0.32% |
| **投影 Spatial Dual** | **0.085188** | 比基线低 2.73%，比全局视觉低 3.04% |

空间视觉模型的最佳验证 MAE 为 0.087531，最佳 Epoch 为 23，测试 MSE 为 0.036140。它是当前项目最后一轮 Mini-VLA 实验，表明在该数据划分和 Seed=42 下，保留粗粒度空间关系可将视觉信息转化为测试集收益。

![最终空间视觉模型与对照的测试 MAE](figures/final-spatial-comparison.svg)

## 结论边界

- 结论来自项目实验输出记录；公开仓库没有原始数据、代码、缓存、模型权重或完整日志，无法在仓库内独立复算。
- 最终空间视觉结论基于单个随机种子和离线动作预测；它支持当前设置下的增量价值，不代表所有任务、数据划分或真实机器人执行都稳定提升。
- 项目完成了数据/缓存质检、控制变量、反事实干预、表示迭代和复评；未完成真实机器人失败后的补采、Dataset V2 与再训练。
