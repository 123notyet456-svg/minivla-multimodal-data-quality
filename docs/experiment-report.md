# Mini-VLA 实验报告

> 证据说明：本报告数字与配置来自当前项目分析文档。原始日志、指标导出、代码和数据修订号未包含在本仓库或当前项目资料目录中，故无法在此独立复算；引用结果前请与原始实验记录核实。

## 实验设置

数据集为 lerobot/libero_10：10 个任务、379 条 Episode（轨迹）、101,469 帧。按 Episode-level Stratified Split（轨迹级分层划分）拆分为训练/验证/测试 303/38/38 条轨迹，对应 81,126/10,118/10,225 帧。输入为双 RGB 视角、8 维 State、384 维 Language，输出为 7 维 Action。视觉编码器为 ImageNet 预训练、冻结的 MobileNetV3-Small，每路输出 576 维特征。

## 四组控制变量实验

保持数据划分、State、Language、动作标签及训练条件一致，只改变视觉输入。

| 模型 | 测试 MAE | 相对 State+Language |
|---|---:|---:|
| State + Language | **0.088374** | 基线 |
| Main + State + Language | 0.096104 | +8.75% |
| Wrist + State + Language | 0.094052 | +6.42% |
| Dual + State + Language | 0.093733 | +6.06% |

简单拼接融合下，加入视觉没有超过 State+Language 基线。这不说明视觉无价值，只说明此配置没有获得测试集泛化收益。

## 测试时视觉干预

固定同一个 Dual Mini-VLA、State、Language、测试集和动作标签，只改变视觉特征。

| 条件 | MAE | 相对正确视觉 | 动作预测变化幅度 |
|---|---:|---:|---:|
| 正确视觉 | **0.093733** | 0% | 0 |
| 主相机置零 | 0.170221 | +81.60% | 0.142918 |
| 腕部相机置零 | 0.171370 | +82.83% | 0.143295 |
| 双相机置零 | 0.253782 | +170.75% | 0.236544 |
| 全局错配视觉 | 0.278478 | +197.10% | 0.268715 |
| 同任务内错配视觉 | 0.266721 | +184.55% | 0.254821 |

结果支持模型依赖两路视觉，且错误视觉比无视觉风险更高；相机贡献不能据此线性拆分。

## 时间错位干预

LIBERO 帧率为 10 FPS。仅沿同一轨迹时间轴错位视觉。

| 视觉错位 | MAE | 相对正确视觉 | 动作预测变化幅度 |
|---:|---:|---:|---:|
| 0 秒 | **0.093733** | 0% | 0 |
| 0.1 秒 | 0.094475 | +0.79% | 0.036200 |
| 0.5 秒 | 0.112833 | +20.38% | 0.077297 |
| 2 秒 | 0.222641 | +137.53% | 0.198413 |
| 5 秒 | 0.322359 | +243.91% | 0.303866 |

误差和预测变化随错位扩大而增大，支持当前设置下模型利用时间敏感视觉状态；该实验不识别具体物体位置等单一因素的独立因果贡献。

## 融合策略迭代

投影融合将主/腕视觉、State、Language 分别投影为 256/256/64/128 维后再融合。

| 模型 | 测试 MAE | 对应比较 |
|---|---:|---|
| 简单融合 State + Language | 0.088374 | 基线 |
| 简单融合 Dual | 0.093733 | 视觉劣于基线 6.06% |
| 投影融合 State + Language | **0.087578** | 投影架构基线 |
| 投影融合 Dual | 0.087860 | 比投影基线高 0.32% |

投影融合 Dual 相比简单融合 Dual 的 MAE 下降 6.27%。视觉模型训练误差更低但测试没有明确优势，属于视觉过拟合信号；视觉信息增益仍未被确认。

## 结论边界

已完成数据/缓存质检、控制变量对照、反事实失败定位、融合改进和复评。未完成根据真实机器人失败补采新轨迹、形成 Dataset V2 并再训练，因此项目属于离线实验迭代，不是完整真实数据采集飞轮。
