# 数据字段与特征缓存质检

## 数据字段检查

`lerobot/libero_10` 的项目检查记录为：10 个任务、379 条轨迹、101,469 帧、10 FPS、2 路相机、8 维 State 和 7 维 Action。两路 RGB 字段为：

| 字段 | 含义 | 检查结果 |
|---|---|---|
| `observation.images.image` | 主相机 RGB | 存在 |
| `observation.images.wrist_image` | 腕部相机 RGB | 存在 |
| `task_index` | 任务编号 | 10 个任务均覆盖 |
| State | 机器人状态 | 8 维 |
| Action | 动作标签 | 7 维 |

每条 Episode 只归属一个任务，任务分布覆盖 10 个任务。一个关键数据字段发现是：`meta/tasks.parquet` 提供 `task_index`，但不直接提供自然语言文本；项目通过 LIBERO Benchmark 中的任务定义建立 `task_index → instruction` 映射，避免把任务编号误当作语言字段。

## 语言数据质检

- 检查任务编号与语言映射完整性。
- 为每个任务建立同义改写指令；原始指令与改写指令的余弦相似度范围为 0.9644–0.9846。
- 用确定性错排构建错误语言，对训练、验证、测试的 Episode 和帧级匹配均为 0，同时保持任务分布。
