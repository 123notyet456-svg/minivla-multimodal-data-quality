# 语言条件与测试时干预

## 任务条件基线

项目先验证“知道正在做哪个任务”是否有增量价值。输入为 State 加 10 维 One-hot Task ID（独热任务编号），并保持轨迹级分层划分。语言条件阶段记录的训练/验证/测试为 303/38/38 条轨迹，对应 81,266/10,232/9,971 帧；它与后续 Mini-VLA 阶段的帧数不同，因此结果只在各自阶段内比较。

| 模型 | Overall MAE |
|---|---:|
| State-only | 0.10147 |
| State + Zero Task | 0.10892 |
| State + Shuffled Task | 0.11296 |
| State + Correct Task | **0.09484** |

正确任务编号较 State-only 改善 6.54%，较零任务和错配任务分别改善 12.93% 与 16.04%，支持任务身份包含状态之外的动作相关信息。

## 语言条件

语言指令经冻结的 MiniLM 编码为 384 维向量。初轮重新训练的错配语言模型 MAE 为 0.09340，几乎接近正确语言模型 0.09280；项目因此没有把该结果当作语义理解证据，而是定位到 Codebook Effect（编码表效应）：模型可能将稳定的错误嵌入重新学习为任务标签。

## 固定模型的测试时干预

为去除编码表效应，固定正确语言模型的所有权重、State、测试集与动作标签，只改变语言输入。

| 测试语言 | MAE | 相对正确语言 |
|---|---:|---:|
| 正确语言 | **0.092803** | 0% |
| 同义改写 | 0.094063 | +1.36% |
| 零语言 | 0.220663 | +137.77% |
| 9 种错误语言的平均值 | 0.238319 | +156.80% |
| 最佳错误语言 | 0.205250 | +121.17% |

固定模型后，删除或改错语言均显著拉高误差；这比“重新训练错配模型”更直接地支持策略依赖正确语言条件。同义改写只带来 1.36% 的误差变化，说明在 10 个已知任务和相近表达范围内存在初步语义鲁棒性。

## 结论边界

这些实验没有测试未见任务、未见物体组合、复杂表达或组合泛化。因此可以表述为“当前已知任务范围内的语言条件依赖”，不能表述为对任意自然语言的普适理解。
