# 证据范围与复现边界

## 已核对的项目记录

本档案依据项目对话中保留的实验输出、阶段报告和代码/产物路径记录整理，覆盖：

- LIBERO 数据字段、任务覆盖、语言映射与缓存质检；
- Task ID 与语言条件的控制变量结果；
- 固定模型的语言、视觉与时间错位干预结果；
- 投影融合和空间视觉的最终比较，包括 Seed=42、最佳 Epoch、验证 MAE、测试 MAE/MSE。

## 未随仓库公开的材料

本仓库没有公开原始数据、RGB 帧、特征缓存、训练/评测代码、CSV 日志、语言缓存、权重和检查点。文档中的数值可追溯到项目实验记录，但外部查看者不能只凭本仓库重新执行计算。

## 正确使用方式

将本仓库作为实验设计、数据质量方法和结果叙事的展示页。使用最终空间视觉指标时，应同时保留“单 Seed 的离线动作预测结果”这一限定；新增可复现实验资产前，应补充版本、哈希、随机种子、命令及完整输出。
