# 证据范围与复现边界

## 已核对的项目记录

本档案依据项目对话中保留的实验输出、阶段报告和代码/产物路径记录整理，覆盖：

- LIBERO 数据字段、任务覆盖、语言映射与缓存质检；
- Task ID 与语言条件的控制变量结果；
- 固定模型的语言、视觉与时间错位干预结果；
- 投影融合和空间视觉的最终比较，包括 Seed=42、最佳 Epoch、验证 MAE、测试 MAE/MSE。

## 已公开的结果表与未公开的材料

`results/` 提供 15 份小型 CSV 结果表，覆盖任务/语言条件、视觉与时间错位干预、数据切分与缓存质检、投影融合、空间视觉对照及训练曲线。这些表是从原项目报告目录筛出的聚合结果，不含样本级 RGB、预测明细或模型产物。

本仓库没有公开原始数据、RGB 帧、特征缓存、训练/评测代码、完整原始日志、语言缓存、权重和检查点。文档与结果表中的数值可追溯到项目实验记录，但外部查看者不能只凭本仓库重新执行计算。

## 正确使用方式

将本仓库作为实验设计、数据质量方法和结果叙事的展示页。使用最终空间视觉指标时，应同时保留“单 Seed 的离线动作预测结果”这一限定；新增可复现实验资产前，应补充版本、哈希、随机种子、命令及完整输出。
