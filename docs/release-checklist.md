# GitHub 发布前检查

## 本次检查结果

- 仓库仅包含 Markdown 文档与忽略规则；不含代码、原始数据、模型权重、检查点、日志、图片或 Notebook 输出。
- 已写入 .gitignore，排除常见密钥、数据目录、模型权重、检查点、日志和本地生成文件。
- 文档仅保留项目分析文档中记录的配置和聚合指标；当前项目镜像未提供原始实验材料，文档已明确这一限制。未公开数据样本、绝对路径、访问令牌、个人信息或内部链接。
- 已核对数据集和模型的公开来源及许可说明；上游数据许可表述存在差异，仓库不再分发数据或权重，细节见来源与许可说明。
- 本仓库没有自有 `LICENSE` 文件；仓库公开不等同于授予复制、修改或再分发权利。
- 当前仓库不含任何大文件。后续加入资产时，需重新审查单文件大小、总仓库大小、授权和历史提交。

## 发布后维护规则

1. 原始 LIBERO 数据、模型权重、训练检查点和任何未获授权的第三方材料不提交 Git。
2. 代码、配置、图表和日志先检查密钥、个人信息、绝对路径、私有 URL 与 Notebook 单元输出，再提交。
3. 若新增可复现实验代码，README 必须同步补充依赖版本、随机种子、运行命令、数据版本和结果复核方式。
4. 如需引用原始数据或模型，使用其官方页面或经确认可公开的链接，不复制数据或模型资产。
5. 每次发布前执行暂存区检查和大文件检查；确认实验结论没有超出报告的证据边界。
