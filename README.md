# Mini-VLA：多模态数据质检与视觉价值实验

本仓库整理 LIBERO-10 上的 Mini-VLA（Vision-Language-Action，视觉—语言—动作）离线实验，重点是数据质检、控制变量和反事实干预。

## 结果摘要

本仓库中的数字来自项目分析文档。当前可用工作区未包含原始报告、实验日志、训练代码或指标导出文件，因此这些数字尚不能由仓库内容独立复算；简历引用前请与原始实验记录核对。

| 维度 | 项目分析文档记录 |
|---|---|
| 数据规模 | 10 个任务、379 条轨迹、101,469 帧 |
| 输入与目标 | 主/腕双 RGB 视角 + 8 维机器人状态 + 语言 → 7 维动作 |
| 数据划分 | 轨迹级分层划分：训练/验证/测试为 303/38/38 条轨迹；81,126/10,118/10,225 帧 |
| 视觉表示 | 冻结的 ImageNet 预训练 MobileNetV3-Small；每个视角 576 维特征 |
| 对照结论 | 双视觉简单融合 MAE 为 0.093733，较 State+Language 的 0.088374 高 6.06%，未验证视觉泛化增益 |
| 反事实证据 | 双视觉置零 MAE 为 0.253782（+170.75%）；全局错配视觉为 0.278478（+197.10%） |

MAE（Mean Absolute Error，平均绝对误差）越低越好。

## 结论边界

1. 测试时删除、错配或时间错位视觉都会显著抬高误差；同任务内换帧也使 MAE 增加 184.55%，支持模型使用帧级视觉状态。
2. 投影融合将双视觉 MAE 从 0.093733 降至 0.087860，改善 6.27%；但仍略高于同架构 State+Language 的 0.087578，差距 0.32%。因此不能宣称视觉已经超过状态和语言基线。

## 仓库范围

本仓库仅公开实验记录和聚合指标，不含原始数据、模型权重、检查点、密钥或私有路径。当前工作区没有可公开的训练代码和原始日志，因此不承诺端到端复现。

本项目完成的是“数据质检 → 基线与消融 → 反事实失败定位 → 融合策略改进 → 复评”的离线实验迭代闭环；尚未完成真实机器人失败后补采数据并再训练的完整数据采集飞轮。
